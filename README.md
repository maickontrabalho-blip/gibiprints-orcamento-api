# GIBIPRINTS — Nova Linha V2

Versão de teste do projeto completo.

## Nova função
- Produtos → Nova linha abre o cadastro exclusivo de linhas/mostruários.
- Título personalizado após `LINHA:`.
- Modelos pré-definidos: Gola Polo Masculino, Gola Polo Feminino, Camisa Comum, Baby Look e Regata.
- Fotos e especificações por modelo.
- Linhas ficam disponíveis também na aba Catálogo para consulta/envio.
- Linhas não entram nas exportações PDF/JPG do catálogo.
- Backup/restore inclui as linhas e suas fotos.
- Ao salvar uma linha com sessão na nuvem, ela é incluída no último backup da nuvem.
- Exportação Enviar Linha não exibe preços.
