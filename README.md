# GIBIPRINTS — Nova Linha V3

Versão de teste da função Linhas / Mostruários.

## Para atualizar um projeto já instalado
Substitua somente:
- `index.html`
- `service-worker.js`

Os demais arquivos da versão anterior permanecem iguais.

## Alterações
- Exportação da Linha sem qualquer texto de preço/valor.
- Imagem principal maior e cards inferiores redistribuídos.
- Linhas aparecem no Catálogo administrativo em carrossel infinito.
- Modelos de cada Linha aparecem em carrossel infinito com swipe e setas.
- O carrossel das Linhas e o carrossel dos Modelos são independentes.
- Backup/restauração das Linhas continua no snapshot existente.
- Exportação normal do Catálogo não inclui Linhas.
